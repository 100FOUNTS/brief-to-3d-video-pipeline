# Documentation index

The documents fall into two groups: **guides** (read them to learn or to decide) and **history** (read them to see how it really went, including the mistakes).

## Guides

| Document | Read it when you want to… |
| --- | --- |
| [`exercise-plan.md`](exercise-plan.md) | **Do the exercise yourself.** Phases 0–7 with the prompts, why each phase exists, a success criterion and a schedule. |
| [`pro-pipeline.md`](pro-pipeline.md) | See, stage by stage (19 stages), which professional or frontier tool replaces what we did, how it is automated and what it costs. |
| [`professional-level.md`](professional-level.md) | Understand how this kind of work is done professionally, with prices and the reliability label of every source. |
| [`inventory.md`](inventory.md) | Know exactly what was used: models, programs, libraries, versions, licenses, and what was changed outside the project folder. |

## History

| Document | Read it when you want to… |
| --- | --- |
| [`journal.md`](journal.md) | Follow what happened in order: every failure, its cause and its fix. The most useful document for avoiding the same traps. |
| [`retrospective.md`](retrospective.md) | Get the one-page summary: what worked, the technical lessons, which model to use for what, and recurring mistakes. |

## Data and generated files

| File | What it is |
| --- | --- |
| [`metrics.csv`](metrics.csv) | One row per attempt (phase, model, estimated minutes, attempts, result, notes). The minutes are estimates. |
| [`script.json`](script.json) | The voice script with start and window per scene. **Generated** from `brief.json`: do not edit by hand. |
| [`img/`](img) | Images used in the README, kept as they were generated (the video and the product text are in Spanish). |
