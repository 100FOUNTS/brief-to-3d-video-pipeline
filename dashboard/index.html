Resultado de cada fase

Esfuerzo acumulado (minutos) a lo largo del ejercicio

Consulta SQL de este gráfico
SELECT fase,
       SUM(minutos) OVER (ORDER BY orden) AS minutos_acumulados
FROM m
ORDER BY orden;
