Minutes per phase (estimated)

SQL query for this chart
SELECT phase, SUM(minutes) AS minutes
FROM m
GROUP BY phase
ORDER BY MIN(position);

Attempts until accepted, per phase

SQL query for this chart
SELECT phase, SUM(attempts) AS attempts
FROM m
GROUP BY phase
ORDER BY MIN(position);

Result of each phase

SQL query for this chart
SELECT result, COUNT(*) AS phases
FROM m
GROUP BY result;

Cumulative effort (minutes) over the exercise

SQL query for this chart
SELECT phase,
       SUM(minutes) OVER (ORDER BY position) AS cumulative_minutes
FROM m
ORDER BY position;

Experiment (same task, same evaluator): % of checks passed (requirements + extra quality)

SQL query for this chart
SELECT participant, ROUND(100.0 * passed / total, 1) AS pct_passed
FROM experiment
ORDER BY pct_passed DESC;

Experiment: seconds until finished

SQL query for this chart
SELECT participant, ROUND(seconds, 0) AS seconds
FROM experiment
ORDER BY seconds;
